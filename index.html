THE CORE IDEA

One assistant. Multiple execution paths.

IRIS is not tied to a single AI model or a single execution environment. The system is designed so the user can choose local, cloud, or hybrid operation.

◉

Local Intelligence

Run supported AI workloads locally when privacy, offline access, or device-side processing matters.

◇

Hybrid Intelligence

Let the IRIS Core intelligently route work between local and cloud execution according to the task.

◎

Cloud Intelligence

Use cloud models when you want cloud processing and do not want local inference to consume device resources.
