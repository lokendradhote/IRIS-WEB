EXECUTION MODES

Choose how IRIS works.

The user decides whether IRIS should route intelligently or use one execution environment explicitly.

MODE 01

Local

Use local AI execution only.

  • Local model is activated.
  • Useful when privacy or offline capability is important.
  • Cloud execution is not selected for the task.
  • Inference uses device resources.
MODE 02

Hybrid

Allow the IRIS Core to intelligently choose.

  • Local and cloud execution can work together.
  • The IRIS Core acts as the routing layer.
  • Best suited for efficient, adaptive operation.
  • The user explicitly grants the router this freedom.
MODE 03

Cloud

Use cloud AI execution only.

  • Cloud model is activated.
  • Local inference is not used for the selected task.
  • Useful when you do not want local compute resources consumed.
  • Suitable when cloud intelligence is preferred.

WHY THREE MODES?

Flexibility without taking control away from the user.

Hybrid mode is the intelligent option, but it is not the only option. A user may have a strong reason to keep processing local, or may prefer cloud execution without using local device resources.

IRIS therefore exposes all three modes instead of silently switching between local and cloud processing without the user's chosen policy.
