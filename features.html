CURRENTLY IMPLEMENTED AI FEATURES

What IRIS can do.

A system layer around AI — not a wrapper locked to one model.

The following describes the current feature set and the architectural direction represented by the project.

01

MODEL FLEXIBILITY

IRIS is not dependent on a single model.

The architecture is designed so the underlying AI model can be changed. Whether the selected model is local or cloud-based, IRIS is not built around a permanent dependency on one specific model or provider.

This makes the model an interchangeable intelligence component rather than the entire identity of the assistant.

02

MEMORY & DATABASE

Persistent memory and conversation data are separate concepts.

Memory contains information that the user explicitly asks IRIS to remember, as well as information IRIS may decide to save as a persistent fact.

Database stores chat and conversation data. Keeping these concepts separate makes the system easier to manage and evolve.

03

VOICE

Voice input can remain user-controlled.

In normal voice input, speech is converted to text and placed into the input box. The user can then modify it, delete it, or send it — the user remains in control.

Listening→User Input→STT→IRIS Processing→Output→TTS→Voice Output↻

In Voice-to-Voice mode, IRIS can continue the loop by listening again after producing the voice output.

04

TOOLS

IRIS can interact with the local system and the web.

System StatusCPU, RAM, battery and other system telemetry.
Application LaunchingSearch for applications available on the device and launch them.
Web SearchSearch the web for information and current sources.
File OperationsOpen, find and work with files on the device.
05

WEB CAPABILITIES

Web grounding can extend what the model knows.

When web capabilities are used, IRIS can obtain information from web search and use the selected AI model to process that information into an answer. This creates a path between current web information and the assistant's reasoning.

06

DESKTOP INTERFACE

A configurable PySide6 desktop experience.

The current interface includes chat/workspace controls, voice-to-voice state, engine state, settings, memory management, layout/theme controls, data and storage controls, project folders, pinned chats and conversation management.

PySide6Dark / Light UIAccent ThemesMemory VaultData & StorageProject Workspaces

Some settings visible in the current interface are still subject to further implementation and verification. The documentation should distinguish implemented functionality from planned controls.
