HYBRID ROUTING

One core, different execution paths.

In Hybrid mode, the IRIS Core can decide whether a task should use local intelligence, cloud intelligence, or supporting tools. The user can also bypass intelligent routing by explicitly selecting Local or Cloud mode.

The goal is not to restrict the router, but to give the user control over whether the router is allowed to choose the execution path.

ARCHITECTURAL COMPONENTS

Designed as replaceable layers.

IRIS Core

The orchestration and routing layer that coordinates models, tools, context and execution mode.

Model Layer

Local and cloud models can be treated as interchangeable intelligence providers.

Memory Layer

Stores persistent information that IRIS or the user chooses to retain.

Chat Database

Stores conversation and chat data separately from persistent memory.

Tool Layer

Provides access to system status, applications, files and web search.

Voice Layer

Connects listening, speech-to-text, processing, text-to-speech and voice output.
