# IRIS Official Website

**IRIS — Intelligent Response & Interaction System**

This is the official project website for IRIS.

## Pages

- `index.html` — Home
- `about.html` — About IRIS
- `features.html` — Current features
- `architecture.html` — System architecture
- `modes.html` — Local / Hybrid / Cloud modes
- `documentation.html` — Documentation hub
- `css/style.css` — Global styling
- `js/main.js` — Mobile navigation and future site interactions

## Repository

https://github.com/lokendradhote/IRIS

## Notes

The website deliberately separates HTML, CSS and JavaScript so each section can be
edited independently. Current-vs-planned functionality should be kept explicit as
the IRIS implementation evolves.
