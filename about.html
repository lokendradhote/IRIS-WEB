ABOUT THE PROJECT

IRIS

Intelligent Response & Interaction System

IRIS is a local-first hybrid personal AI assistant focused on giving the user control over how intelligence is executed, where data is processed, and which AI model is used.

Why IRIS?

Modern AI does not have to mean sending every task to a remote service. At the same time, local AI does not have to mean giving up access to stronger cloud models. IRIS is built around the idea that both approaches can coexist.

The IRIS Core acts as the system's decision layer in hybrid mode, while explicit Local and Cloud modes allow the user to choose the execution environment directly.

“

The user should decide whether intelligence happens locally, in the cloud, or through intelligent routing.

DESIGN PRINCIPLES

Principles behind the system.

Local-first

Keep useful intelligence close to the device whenever local execution is appropriate.

Model agnostic

IRIS is designed around an architecture where the underlying model can be changed without rebuilding the whole system around one provider.

User controlled

Local, Cloud, and Hybrid modes are explicit choices rather than forcing the user into one execution strategy.

Open source

The project source is publicly available on GitHub. The repository contains the implementation and development history of IRIS.
